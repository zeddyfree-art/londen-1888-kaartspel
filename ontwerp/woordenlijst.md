# Woordenlijst

Consistentie is een harde eis. Gebruik deze woorden overal hetzelfde: in kaartteksten, in de spelregels, in de code en in de data.

## Handelingen

| Woord | Betekenis |
|---|---|
| **Spelen** | Een kaart uit je hand gebruiken. Een bondgenoot of barricade zet je in een leeg vak; een spul, spreuk of middeltje gebruik je op een doel. |
| **Toeslaan** | De teller van een kaart op het veld bereikt 0 en ze doet haar actie: aanvallen en/of haar vermogen. Daarna springt de teller terug naar haar maximum. |
| **Treffer** | Een aanval die een doel raakt, ook als die 0 schade doet. Schade door Pest of Doorns is **geen** treffer. |
| **Afleggen** | Een kaart gaat naar de aflegstapel. |
| **Verbannen** | Een kaart is weg tot het eind van het gevecht. |
| **Trekken** | Een kaart van de trekstapel in je hand nemen. Aan het begin van elke beurt trek je aan tot 6. |
| **Schudden** | Is de trekstapel leeg, dan wordt de aflegstapel geschud en de nieuwe trekstapel. |
| **Terugroepen** | Een bondgenoot van het veld terug in je hand nemen. Hij geneest helemaal en verliest al zijn statussen. Kost je beurt. |
| **Verplaatsen** | Een eigen kaart naar een ander vak zetten. Gratis en onbeperkt. |

## Getallen

| Woord | Betekenis |
|---|---|
| **Schade** | Gaat van het Leven af (bondgenoten, vijanden) of van het Lichaam (je held). |
| **Gruwel** | Een tweede soort schade. Op je held gaat Gruwel van de Geest af. Op een bondgenoot geeft elke punt Gruwel 1 Angst. Vijanden hebben geen Geest. |
| **Leven** | Hoeveel schade een bondgenoot of vijand kan hebben. |
| **Lichaam** | Het leven van je held. Op 0 is de run voorbij. |
| **Geest** | Het verstand van je held. Op 0 krijg je een Waanzin-kaart en herstelt de Geest tot de helft. |
| **Schroot** | Het leven van een barricade. Elke treffer kost precies 1 schroot, hoe hard hij ook is. |
| **Teller** | Het klokje op een kaart: na hoeveel slagen ze toeslaat. |
| **Aanval** | Hoeveel schade een kaart doet als ze toeslaat. |
| **Ponden** | Geld. |

## Begrippen

| Woord | Betekenis |
|---|---|
| **Verlicht** | Je Geest staat op de helft of lager. Occulte kaarten gebruiken dan hun verlichte tekst. |
| **Waanzin** | Een vloekkaart die in je stapel komt als je Geest op 0 valt. Raak je kwijt bij de Kerk. |
| **Zegel** | Een kaart met een Zegel zit gegarandeerd in je beginhand en kost geen beurt om te spelen. |
| **Golf** | Een groep vijanden die tegelijk binnenkomt. Big Ben telt af naar de volgende golf. |
| **Gewond** | Een bondgenoot die viel. Halve aanval en half Leven tot hij verzorgd wordt (Ziekenhuis of Logementen). |
| **Straat** en **Riool** | De bovenste en de onderste rij van het slagveld. |
| **Voorste vak** | Het vak het dichtst bij het midden. |
| **Trofee** | Kracht: een kaart die een vijand doodt, krijgt +1 aanval voor de rest van het gevecht. |

## Statussen

| Status | Werking | Afbouw |
|---|---|---|
| **Mist** | Teller en reacties staan stil | −1 per beurt |
| **Pest** | Aan het eind van de beurt evenveel schade (geen treffer) | −1 per keer |
| **Doorns** | Wie deze kaart treft, krijgt evenveel schade (geen treffer) | blijft |
| **Gezegend** | Blokkeert de volgende treffer volledig | −1 per geblokkeerde treffer |
| **Bescherming** | Vangt schade op voordat het Leven daalt | verbruikt |
| **Vervloekt** | Volgende treffer doet dubbele schade | weg na die treffer |
| **Inkt** | Vermogens en reacties doen niets | −1 per beurt |
| **Bekoring** | Volgende aanval treft de eigen kant | weg na die aanval |
| **Angst** | −1 aanval per punt | −1 na elke eigen aanval |
| **Woede** | +1 schade per punt bij de volgende aanval | weg na die aanval |

## Kenmerken

| Kenmerk | Werking |
|---|---|
| **Salvo** | Raakt de hele rij. |
| **Scherpschutter** | Valt de zwakste vijand aan. |
| **Achterhoede** | Valt de achterste vijand aan. |
| **Trofee** | Zie hierboven. |
